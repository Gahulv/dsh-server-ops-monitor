# DSH 服务器工作区设计预览

直接双击同目录 index.html 即可在浏览器打开，无构建、无依赖、无需服务。页面始终标注“设计预览 · 示例数据”，不发起网络请求，不连接服务器，不执行命令。

正式组件方向：沿用 DSH 原生 React 与 slots。此预览只用 HTML/CSS/JavaScript 模拟，不接入正式 UI。

- 布局：左侧窄聊天，右侧同一服务器的 CPU、内存、磁盘、网络与命令输出。740px 以下上下排列，指标改为两列，长日志折行并仅纵向滚动。
- 字体：系统字体；命令与日志使用系统等宽字体。
- 配色：页面 #f7f8fa，面板 #ffffff，正文 #253043，次要文字 #718096，焦点蓝 #356cc9，正常状态绿 #37816a；暂停使用少量琥珀色。
- 交互：暂停/恢复本地日志；切换三条执行历史；点击面板标题折叠/展开。指标每两秒模拟变化，日志最多保留 80 行。
- 动效：切换与展开 150ms；prefers-reduced-motion 时关闭动效。
- 取舍：优先对话与输出的阅读密度，采用浅色日志区域；历史选择复用浏览器原生 select 保持键盘可用性。
